# WavLM 情绪微调标注指南

本标注台面向 `tiantiaf/wavlm-large-categorical-emotion`。当前模型的公开情绪头是
9 类单标签 softmax，而不是音频级多标签分类器。因此，准确标注的关键不是给整段
音频堆叠多个标签，而是把音频切成可学习的人声片段。

## 推荐流程

1. 先完整播放一遍，标出有清晰人声的位置；环境声、静音、音乐和无法分辨的人声不入训。
2. 再从头播放，在情绪变化、说话人切换或明显停顿处切分。通常每段至少 1 秒；短促而明确的
   尖叫、哭喊或惊呼可以更短。
3. 每个片段只选一个最突出的“主情绪”硬标签；训练准备时再把多人、重叠区间的硬标签聚合为
   9 类软标签分布。
4. 若确实同时有较弱的第二种情绪，记录为最多两个“辅助情绪”；它们保留给人工复核，不能与
   主情绪一起直接作为当前 softmax 的训练标签。
5. 对重叠说话、低信噪比、边界不清或判断把握不足的片段，标记“多人重叠说话”或“需复核”，
   并设置低把握程度。训练集导出后应优先排除或由复核人裁决这些样本。

## 一段音频出现多种情绪时

| 情况 | 标注方式 | 是否可直接用于当前模型训练 |
| --- | --- | --- |
| 同一人先平静后愤怒 | 分成两个连续片段，分别标 `Neutral` 和 `Anger` | 可以 |
| 同一片段愤怒为主、夹杂恐惧 | 主情绪 `Anger`，辅助情绪 `Fear`，在备注写明依据 | 主情绪可以；辅助仅供复核 |
| 两位说话人同时发声且情绪不同 | 为每位说话人建立独立片段并标记“多人重叠说话” | 建议复核后再决定，通常不直接入训 |
| 听不清是悲伤还是恐惧 | 选最接近的主情绪并标“需复核”；若没有可靠依据，整段标为不适合 | 暂不直接入训 |
| 纯背景声、音乐或没有有效人声 | 标记整段“音频不适合标注”，不要误标 `Neutral` | 不可以 |

`Neutral` 表示可辨识人声中没有突出的目标情绪，不等于“音频没有风险”；`Other` 仅用于确实
无法归入 8 个明确类别的人声，不应用作不确定性的替代。不能把 `Neutral` 或 `Other` 作为辅助情绪。

## 协作和一致性

- 建议每个音频至少由两位标注者在未查看彼此结果时独立完成。
- 平台会保存同一用户和不同用户的每次提交版本，并显示标注次数；系统不自动用简单投票覆盖原始标注，
  因为不同标注者的片段边界可能并不相同。
- 建议优先复核以下样本：少于两份标注、多人重叠、低把握、标为需复核，或不同标注者给出明显不同的
  主情绪。
- 在准备训练集时，应仅选择音频可用、主情绪清楚、边界可靠、经复核通过的片段；保留原始 JSONL
  以便追溯每个训练样本的判断来源。

## 重复与交叉片段如何生成训练样本

同一段声音被多人重复标注时，不能把每条记录直接当成独立训练样本，否则标注次数多的音频会被重复
加权。训练集生成时应先按音频合并标注，再生成唯一的训练窗口：

1. 收集同一音频所有可用、非重叠说话、无需复核的片段，并保留标注者身份；同一人的多个历史版本默认
   只取最新版本，除非旧版本已被指定为复核结论。
2. 将全部片段的开始和结束时间合并为边界，切成互不重叠的最小时间区间。例如一人标了 `0-8 秒`，
   另一人标了 `4-12 秒`，先切成 `0-4`、`4-8`、`8-12` 三个区间。
3. 对每个最小区间，统计所有覆盖该区间的主情绪硬标签，并使用 1–5 级把握程度作为权重。例如愤怒
   的把握程度为 5、恐惧为 1，则软标签为 `Anger=5/6, Fear=1/6`。相同把握程度的重叠标注就是普通
   算术平均。
4. 微调当前 9 类 softmax 头时使用 soft cross-entropy：`loss = -sum(target * log_softmax(logits))`。
   同一区间的平均把握程度除以 5 得到 `sample_weight`，再用于缩放该样本损失。这样既保留标注分歧，
   也降低低把握样本对模型的影响。
5. 相邻区间在主情绪和说话人一致时可以合并，但输入 WavLM 的最终窗口仍建议保持 3 到 15 秒。过短区间
   可与同标签相邻区间合并；无法合并、多人同时说话或边界争议过大的区间应排除。

这样处理后，一段物理音频在同一时间范围内只产生一份训练输入；多人标注用于提高目标可信度，而不是
机械增加样本数量。训练集划分必须按原始音频分组，保证同一音频的不同窗口不会同时出现在训练集和验证集。
